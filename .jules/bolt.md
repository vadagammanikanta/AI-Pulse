## 2025-02-18 - [Regex compilation overhead in tight loops]
**Learning:** Recompiling regular expressions in loops (e.g., matching a list of keywords against strings for every item in a feed request) introduces massive overhead in Python. While converting a list of keywords to a single regex string with alternation (`|`) is the fastest, it fails to correctly extract overlapping keyword matches, breaking the expected behavior. Furthermore, managing global caches requires thread-safety (atomic assignment) when operating in concurrent environments like FastAPI.
**Action:** Precompile and cache regexes globally in a dictionary/list structure rather than recompiling them on every function call. When dynamically generating caches based on settings that can change at runtime, implement cache invalidation by comparing the current settings state against the cached state. Ensure all updates to global caches are done via atomic variable assignments to prevent concurrency race conditions where another thread might read partially formed data.
